☀️ 开源之夏是什么活动

开源之夏是中国科学院软件研究所发起的“点亮计划”系列活动，旨在鼓励高校学生积极参与开源软件的开发维护，培养和发掘更多优秀的开发者，促进优秀开源软件组织和基础软件生态的蓬勃发展，助力开源软件供应链建设。活动联合各大开源组织，针对重要开源软件的开发与维护提供项目开发任务，并向全球高校学生开放报名。学生可自主选择感兴趣的项目进行申请，中选后在项目开发者（组织导师）的指导下进行开发。根据项目的难易程度和完成情况，结项者将获取开源之夏活动劳务报酬和结项证书。

点亮计划-开源之夏于 2020 年正式发起，在过去六年时间里，以开源软件可靠供应链建设为核心，以点亮开源软件供应链上的“暗点”为目标，累计吸引288家开源社区发布3487个项目任务，来自全球1026所高校的12257名学生报名参与，成功解决2794个实际项目问题，成果均随各开源软件新版本发布并落地应用。点亮计划逐步形成了产业参与开源社区、社区凝聚锻炼人才、人才持续服务产业的闭环格局。

2026年起， 点亮计划正式步入2.0时代——面向AI时代，以基础软件为技术核心，以RISC-V为生态重心。开源之夏以真需求为牵引，通过实战模式培养基础软件紧缺人才，重点支持RISC-V生态建设任务，全面聚焦操作系统、编译器、工具链、数据库、虚拟化栈、人工智能等关键领域，进一步强化开源协同创新，持续推动RISC-V的生态成熟和繁荣。

💁 活动主办方

本次活动由中国科学院软件研究所主办，中国科学院软件研究所智能软件研究中心承办。

开源之夏2026有什么新的变化

🕙 时间变化：活动周期内各流程阶段持续开放报名。

🆕 新增模式：除常规项目开发模式外，新增由学生全程参与主导的领航模式。详见领航模式参与指南。

💡打破时空限制，项目发布和开发时间不固定期限，贴近实际产业需求，更多深入项目机会。

🎭活动角色

🔵 组委会：组委会是由主办方安排的工作人员组成，负责活动的组织与管理。

🟢 组织：包含开源组织/企业，负责提供项目列表和描述，并安排项目对应的导师，按活动规则推进相应进程工作。

🟡 组织导师：组织针对每一个项目指定一个组织导师，导师负责项目详情和细节撰写，指导学生制定合适的开发计划和方案，并按计划完成开发。

🟣 高校学生：学生自由选择项目，与组织导师沟通实现方案并撰写项目计划书。被选中的学生将在组织导师指导下，按计划完成开发工作，并将成果贡献给组织。成功结项的学生获得活动劳务报酬和结项证书。

🟢 关于组织-哪些组织可以参加？

  • 企业（满足以下任一条件）：

    • 拥有 RISC-V 软硬件产品

    • 企业为 RVI 会员

    • 开源软件上游面向 RV 架构支持的贡献记录

  • 开源组织

    • 以核心基础软件类为主（详见组织指南）。

    • 开源组织应公开运营半年以上。

    • 开源组织仓库应采用 OSI 组织认证的开源协议 或 OKF 推荐的开放协议等。

  • 具体参见 组织指南。

🟡 关于导师-如何成为项目导师？

  • 组织针对每个项目需要指定一名导师，导师负责项目的具体内容设计，导师一般应是与该项目相关的开发者（Maintainer、Committer、Contributor），每位导师最多可指导两个项目。

  • 🚫 导师不得同时以学生开发者身份参加本活动，如在活动过程中发现此情况，组委会将取消其参与资格、并不予发放其作为学生所获得的劳务报酬及证书。

  • 具体参见 导师指南。

🟣 关于学生

1. 谁可以报名？

  • 本活动面向年满 18 周岁的高校在校学生。

  • 提交申请时须注意项目开发周期内，学生应是在读状态。若已收到硕士或博士研究生录取通知，可提供录取通知书及相关说明材料。

  • 🚫 学生开发者不得同时以导师身份参加本活动，如在活动过程中发现此情况，组委会将取消其参与资格、并不予发放其作为学生所获得的劳务报酬及证书。

  • 具体参见 学生指南

2. 不是计算机专业/是低年级，可以申请吗？

👌 可以参加，年满18岁在校生专业不限，年级不限。

3. 一位学生可以申请几个项目？

一名学生同时最多可以申请/承担一个项目任务，落选/结项后可再申请其他项目任务。

4. 项目的劳务报酬是多少？

  • 项目难度分为基础、进阶和挑战三档，对应学生结项劳务报酬分别为 6000 元人民币、9000元人民币和 12000 元人民币。（注：本活动所有劳务报酬数额均为税前人民币金额）。

  • 达成项目产出目标并通过结项考核的学生将获得劳务报酬。

4. 申请书怎么写更容易被导师选中？

可参考 保姆级教程：手把手教你搞定项目申请

5. 中选后，如果中途退出会怎么样？

  • 学生因不可抗力确需中止项目开发的，应当第一时间向项目导师如实说明情况，并向组委会提交邮件说明。经学生、导师及组委会三方确认后，项目按终止处理；该学生不再具备当届结项资格，不发放结项证书及劳务报酬。

  • 学生无正当理由擅自退出项目开发，且未向导师、组织及组委会履行报备义务的，组委会有权将其列入 OSPP 失信名单；被列入名单者，后续不得参与 OSPP 相关活动。

6. 结项报酬接收方式？

  • 结项学生务必确认提供的收款银行卡属于一类银行卡，二类银行卡日转账限额将导致发放失败。
